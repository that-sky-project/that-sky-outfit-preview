# Sky 衣柜 · 光遇换装间 — 部署说明

## 这是什么
一个纯静态网站：打开网页即可在浏览器里查看《光遇》角色并更换 121+ 套服装（身体/鞋/面具/脸/颈饰/发型/帽子/头饰/斗篷/道具 10 类，1335 件物品），所有模型与图标已打包在站内，**访客无需安装 APK、无需导入任何文件**。

## 快速部署（1Panel）
1. 把 `SkyWardrobe` 目录（或本 zip 解压出的 SkyWardrobe 目录）整个上传到 1Panel 的**静态网站**目录（如 `网站 → 创建网站 → 静态网站 → 上传目录`）。
2. 站点根目录指向 `SkyWardrobe/`，入口文件 `index.html`。
3. 打开 `https://你的域名/` 即可使用。不需要 Node/PHP/数据库。

## 本地预览
```bash
cd SkyWardrobe
python -m http.server 8399
# 浏览器打开 http://127.0.0.1:8399/index.html
```

## 功能
- **换装**：右侧 10 个分类 → 点击物品即穿戴到 3D 角色上；搜索框可过滤物品；「加载更多」按钮逐批展开列表。
- **环境光照**：顶部 🌗 切换 黎明/白天/午后/夜晚 四时段游戏内光影。
- **自由光影**：顶部 ☀ 打开面板，可调 背景色/环境光/主光(颜色·强度·方位角·仰角)/补光，实时生效，可「同步当前预设」「重置」。
- **导出**：顶部「导出OBJ」打包 model.obj+model.mtl+贴图(zip)；「导出GLB」导出含贴图的 glTF 二进制（当前姿态烘焙，可直接进 Blender/3D 软件）。
- **视图**：⟳ 旋转开关，◎ 重置视角，⛶ 横竖版切换；拖拽旋转/滚轮缩放/右键平移。

## 数据说明（2026-09-09 更新）
- 图标全部重新裁剪自 **vithai.xyz 的官方图集（UIPackedAtlas 1-41）**，与线上对照站逐像素一致；经典斗篷颜色变体按游戏数据染色（与穿戴模型颜色一致）。
- 1335 件物品的 图标/模型 一一对应（同一 OutfitDefs.json 数据源）。
- 数据来源：光遇 Steam 客户端 / 官方 APK 解包 + vithai.xyz 图集。

## 目录结构
```
SkyWardrobe/
├─ index.html          入口（布局/样式/按钮）
├─ js/
│  ├─ wardrobe.js      主逻辑（分类/网格/穿戴/搜索）
│  ├─ mesh.js          游戏 .mesh 解码（LZ4+骨骼）
│  ├─ sky-core.js      角色构建/材质/光照
│  ├─ exporter.js      OBJ/GLB 导出
│  ├─ features.js      光影面板/分类栏横滚/导出绑定
│  └─ three.min.js 等
├─ data/
│  ├─ outfitdefs.min.json   1335 件物品定义（名称/图标/模型/染色）
│  └─ textures/             角色贴图
├─ meshes/             1029 个模型文件（.mesh）
└─ icons/              1252 个物品图标（PNG）
```
